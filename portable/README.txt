SelectPop 划词助手 · 绿色免安装版（Windows）
==================================================

一句话：选中任意文字，立刻弹出「复制 · 翻译 · 搜索 · 解释 · 总结 · 润色 · 语法检查」窗口，AI 功能接入 DeepSeek。

【快速开始】
  1. 解压本 zip 到一个文件夹（建议路径不含中文和空格，例如 D:\SelectPop）
  2. 双击 Start-SelectPop.cmd 启动
  3. 程序出现在系统托盘（右下角）；在任意软件里用鼠标划选文字，松手即弹出操作窗口

【接入 DeepSeek（解锁 AI 翻译 / 解释 / 总结 / 润色 / 语法检查）】
  右键托盘图标 → 打开设置 → 左侧「AI」：
    1. 到 https://platform.deepseek.com 申请 API Key
    2. 把 Key 填进「API Key」→ 点「测试连接」
    3. 显示可用模型后选一个 → 保存
  未填 Key 时：翻译走网页翻译、搜索走浏览器；AI 类动作会提示需要 Key。

【七个动作】
  · 复制      直接复制选中文字
  · 翻译      网页翻译（无 Key）或 AI 翻译（有 Key，可自定义提示词）
  · 搜索      用浏览器搜索（Bing / Google / 百度 / 自定义）
  · 解释      AI 解释含义、背景或代码（需 Key）
  · 总结      AI 总结要点（需 Key）
  · 润色      AI 润色文字（需 Key）
  · 语法检查  AI 检查语法/拼写并给出修改建议（需 Key）
  弹窗内快捷键：数字 1~7 触发对应动作，Esc 关闭，Ctrl/Cmd+Enter 复制结果。

【常见问题】
  · 划词没弹窗：确认托盘图标在、右键托盘「划词已启用」已勾选；排查日志 .data\logs\selectpop.log
  · 启动闪退：Start-SelectPop.cmd 已带 --no-sandbox（兼容安全软件/沙箱环境）；如仍闪退看日志
  · 快捷键：默认 Ctrl+Shift+Space 打开最近一次划词；被占用会自动改用备用键并提示

【更新方法】
  绿色版不支持自动更新。升级：下载新版 zip，解压覆盖整个文件夹（保留 .data 目录即保留设置和 API Key）。

【数据与隐私】
  · 选中的文字只在本地处理；仅 AI 动作会把文字发给 DeepSeek 接口
  · API Key 用系统安全存储加密保存
  · 所有数据都在 .data 目录，删除整个文件夹即彻底清除
